رَصيد - نسخة تجريبية PWA للموبايل

المحتويات:
- index.html: واجهة التطبيق ومنطق العمل.
- manifest.webmanifest: بيانات التثبيت واسم التطبيق وأيقوناته.
- sw.js: تخزين ملفات التطبيق للعمل دون اتصال بعد أول زيارة.
- icon-192.png و icon-512.png: أيقونات التطبيق.

طريقة التجربة على Android:
1) يجب رفع محتويات هذا المجلد إلى استضافة HTTPS (لا يكفي فتح index.html من مدير الملفات).
2) افتح رابط الموقع في Google Chrome على الهاتف.
3) من قائمة Chrome اختر Install app / تثبيت التطبيق أو Add to Home screen / إضافة إلى الشاشة الرئيسية.
4) افتح رَصيد من أيقونته. بعد أول تحميل يمكن فتح الواجهة دون إنترنت.

ملاحظات مهمة:
- هذه نسخة تجريبية وليست APK ولا يوجد رابط استضافة جاهز ضمن هذا الملف.
- البيانات تحفظ محليًا على الجهاز داخل المتصفح؛ احفظ نسخة احتياطية من الإعدادات دوريًا.
- لا توجد مزامنة سحابية أو ربط بالبنوك.
- لم يتم استيراد بيانات ملف Excel تلقائيًا بعد؛ لا تعتمد عليها كدفتر حسابات نهائي قبل مطابقة الأرقام واختبارها.
